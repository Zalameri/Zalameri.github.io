# zalameri.github.io

Personal portfolio of **Zainab Alameri**, Computer Science (Artificial Intelligence) student at Effat University.

Live site: <https://zalameri.github.io>

## Contents
- Featured projects with full case studies
- Honours, experience and volunteering
- Skills linked to the projects where they were used
- Verified certificates
- CV (web page and PDF)

## Updating
- All text lives in `assets/js/data.js`.
- The project list reads the GitHub profile live. A new repository appears on the site only after the `portfolio` topic is added to it on GitHub.
- `.github/workflows/sync-github.yml` saves a snapshot of the repository list every 6 hours as a fallback.

Built with HTML, CSS and JavaScript.
